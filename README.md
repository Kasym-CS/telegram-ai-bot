# Telegram AI Assistant 🤖

Простой Telegram-бот, интегрированный с OpenAI API (gpt-4o-mini), созданный в рамках подготовки к хакатону **HackAlem AI**.

## Функционал
- Прием текстовых сообщений от пользователя в Telegram.
- Отправка запроса в OpenAI API.
- Возврат сгенерированного ИИ ответа обратно в чат.

## Стек технологий
- Python 3.10+
- `pyTelegramBotAPI`
- `openai`
- `python-dotenv`
